# Mening musiqam (Yandex Music, shaxsiy ilova)

## APK olish (kompyuterga hech narsa o'rnatmasdan)
1. github.com da yangi **private** repo oching.
2. Shu papkadagi hamma narsani (`.github` papkasi bilan) repoga yuklang.
3. Repo → **Actions** → "Build APK" tugagach (4-5 daqiqa) → pastdagi **Artifacts** → `MeningMusiqam-APK` ni yuklab oling.
4. ZIP ichidagi `app-debug.apk` ni telefonga o'tkazib o'rnating (Noma'lum manbalardan o'rnatishga ruxsat bering).

Android Studio bo'lsa: papkani oching → Build → Build APK(s).

## Kirish
- "Yandex orqali kirish" tugmasi: Yandex hisobingiz bilan kirasiz.
- Ishlamasa: "tokenni qo'lda kiritish" qismiga OAuth token yozing.

## Imkoniyatlar
Qidiruv, sevimlilar (yurakcha), pleylistlar, "To'lqin", fon rejimida ijro, bildirishnoma va qulf ekrani boshqaruvi, aralashtirish/takrorlash, uyqu taymeri, ovoz sifati.

Eslatma: bu norasmiy API. Yandex uni o'zgartirsa, ilova yangilanishi kerak bo'lishi mumkin. To'liq sifat uchun Yandex Plus kerak.
